About

從實際專案出發，做出更有價值的產品與工具。

我的 GitHub 紀錄顯示，工作的範圍涵蓋實用工具、內容型產品、資料處理與原型驗證。 這些專案並不是單純的程式練習，而是以「解決真實問題」為目的的產品思考與實作。

從實用型 app、報表與資料工具，到 AI / Agent 類型原型，我們都在探索如何把想法快速驗證並逐步成長成更成熟的產品。
