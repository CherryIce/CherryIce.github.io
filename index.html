About

把問題拆解成清晰的產品方案，再交付給使用者。

我的作品更偏向「產品解法」而非純展示型頁面：我會先理解使用場景，再設計功能與互動，最後用工程方式將它落地。 GitHub 上的多個 repository 反映出我對實用性、效率、工具化設計和原型驗證的重視。

這包括工具型產品、資料處理、實驗型專案、移動端開發與 AI 輔助方向，重點始終是讓想法能夠實際被使用與迭代。

Utility product Cleantrail

讓清潔或流程管理更具結構性與可追蹤性。

Problem

需要一個更清楚的工作流程與狀態追蹤方式，讓實際任務與清單能更有秩序、更容易執行。

Solution

將任務與狀態整理為更直觀、可操作的產品架構，讓使用者能快速理解當前狀態與下一步動作。

Travel utility TripCost

聚焦實際使用場景，將費用規劃與旅程決策變得更加直覺。
