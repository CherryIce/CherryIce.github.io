About

我真正代表性的作品，是“工具效率”与“个人产品”两条线，而不是简单地罗列技术点。

工具类项目：ios-multi-app-cloud-build-system 是 iOS / Flutter 多项目的 GitHub Actions 自动化打包脚本，重点解决自动化构建和协同打包问题； Skills 是基于自身工作习惯定制的 Codex / 开发工具，包含项目初始化、工作流生成和设计稿整理辅助能力。

个人产品线包括：马甲包类项目如 Donesome、TripCost、steady21、Looters、Diary、 ReaderEdit、Almanac、FilePeek、photo、SDPacket、plotproof_lab； 以及独立产品如 langpack-prototype（多平台真实翻译）、NovelReader（iOS 小说阅读器）、 Download（Swift 视频下载组件）、RecoveraStudio（数据恢复）、Unknow（小游戏）。

工具类 ios-multi-app-cloud-build-system

面向 iOS / Flutter 多项目的自动化打包脚本。

Problem

多项目的打包流程冗长，容易出现重复劳动、环境差异和部署复杂问题。

Solution

使用 GitHub Actions 脚本化自动化，统一打包流程，让多应用构建更稳定、更省心。

Stack

GitHub Actions, iOS, Flutter, CI/CD automation
