About

我的作品不是单纯“代码堆砌”，而是围绕真实场景的产品思考。

工具类仓库更偏工程效率：例如 ios-multi-app-cloud-build-system 是基于 iOS / Flutter 项目的 GitHub Actions 自动化打包脚本； Skills 则是围绕自身工作习惯打造的 Codex / 开发工具，覆盖项目搭建、设计稿整理等场景。

个人产品则更偏向“产品化的 App / 工具”，包括生成型马甲包项目如 TripCost、Diary、FilePeek、Almanac、 以及独立开发的 langpack-prototype、NovelReader、RecoveraStudio、Unknow 等。

工具类 ios-multi-app-cloud-build-system

面向 iOS / Flutter 多项目场景的自动化打包脚本。

Problem

多项目、跨环境的打包流程很容易出现重复劳动与配置复杂度高的问题，降低效率也增加出错概率。

Solution

通过 GitHub Actions 和脚本化封装，提升自动化打包效率，让项目发布流程更稳定、更可复用。

Stack

GitHub Actions, automation, CI/CD, iOS, Flutter

个人产品 TripCost / Diary / FilePeek

从“个人工具”逐步发展成具备明显产品方向的实用型 App。

Problem

很多个人场景需要更轻量、更高效率的工具能力，但缺少统一的产品思维和清晰的使用路径。

Solution

将常见使用场景抽象成明显的需求模块，形成工具型产品雏形，兼顾功能价值与实际使用体验。

Stack

Product logic, utility app, mobile workflow, personal tooling
