# CherryIce.github.io

This repository is configured for GitHub Pages and contains a polished personal brand homepage.

## Preview

Open `index.html` directly in a browser, or serve the repo locally with a static server.

## GitHub Pages

Because this repository is named `CherryIce.github.io`, it will be published at:

- https://cherryice.github.io/

## Customize

Update the following sections in `index.html`:

- name and intro
- skill and service descriptions
- project cards and links
- GitHub profile URL
- contact email

## Styling

The visual design is controlled in `styles.css`, and the small interactive enhancement is in `script.js`.
